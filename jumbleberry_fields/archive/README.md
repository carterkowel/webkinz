# Archive

Early reinforcement-learning experiments from before the exact solver existed: a `gym` environment that only chose a box for a single roll (no re-rolls), a tabular Q-learning sketch, and an actor-critic (A2C) notebook.

They are kept for history and are not maintained. The current versions are `../rl_env.py` (full game, masked actions), `../rl_qlearning.py` and `../rl_dqn.py`.
